# Manual instantiation：学习锚点与进度

官方章节：[Providers - Manual instantiation](https://docs.nestjs.com/providers#manual-instantiation)

## 官方内容讲解

通常由 Nest 自动解析依赖；确有需要时，也可以脱离自动注入流程手动取得或创建 Provider。官方在这里提示两种进一步学习的入口：

- `ModuleRef`：在模块上下文中取得已有 Provider，或动态创建 Provider；详见 Module reference。
- Standalone applications：在 `bootstrap()` 中取得 Provider，例如用于独立应用或启动配置。

本节是概念指引，具体能力分别属于上述主题，不在这里一次实现。

## 学习版现状

- [NestFactory](../../@nest/core/nest-factory.ts) 只创建 HTTP 应用，并按模块 `providers` 建立 Provider 实例 Map，供自动注入流程使用。
- [NestApplication](../../@nest/core/nest-application.ts) 目前没有 `get()`；学习版也没有 `ModuleRef` 或 `NestFactory.createApplicationContext()`。
- 因此学习版目前不支持从启动入口手动取得 Provider，也不支持 ModuleRef 的动态查找或创建。

## 当前处理

- 本标题只记录官方提供的两个延伸方向，不新增测试或实现。
- 若继续深入，应分别以 ModuleRef 的已有 Provider 查找或 standalone application context 为独立学习步骤。
