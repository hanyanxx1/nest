# Modules：学习锚点与进度

官方章节：[Modules](https://docs.nestjs.com/modules)

## 官方内容讲解

`@Module()` 用元数据描述应用结构。每个 Nest 应用至少有一个根模块，Nest 从根模块开始组织应用中的模块、Controller 和 Provider。

模块元数据包含：

- `providers`：由 Nest 创建、可在模块范围内注入的 Provider。
- `controllers`：由该模块管理的 Controller。
- `imports`：当前模块依赖的其他模块。
- `exports`：向导入当前模块的其他模块公开的 Provider，构成模块的公共接口。

模块默认封装自己的 Provider；其他模块不能直接注入它们，除非该 Provider 被导出并通过模块关系引入。

## 学习版现状与已有用例

- [`@Module()`](../../../@nest/common/decorators/modules/module.decorator.ts) 把传入的元数据逐项写入类的 Reflect metadata。
- [`ModuleMetadata`](../../../@nest/common/interfaces/modules/module-metadata.interface.ts) 声明了 `imports`、`controllers`、`providers` 和 `exports`。
- [`NestFactory`](../../../@nest/core/nest-factory.ts) 从根模块递归收集 `imports`，为每个模块保留独立的 Provider Map；Controller 构造函数依赖以及 Controller/Provider 属性依赖，可从本模块或直接导入并导出该 Provider 的模块中解析。
- [provider-injection.e2e-spec.ts](../../../test/1_Overview/2_Providers/1_providers/provider-injection.e2e-spec.ts) 已验证根模块登记 `CatsService` 并将其注入 `CatsController`。用户此前报告该测试通过，因此本标题复用这份证据，不新增等价测试。
- [feature-module.e2e-spec.ts](../../../test/1_Overview/3_Modules/2_Feature%20modules/feature-module.e2e-spec.ts) 的 3 个测试已通过，覆盖单层和多层模块导入。
- [shared-module.e2e-spec.ts](../../../test/1_Overview/3_Modules/3_Shared%20modules/shared-module.e2e-spec.ts) 的 1 个测试已通过，验证两个导入同一模块的消费者共享其导出的 Provider 实例。
- [shared-module-property-injection.e2e-spec.ts](../../../test/1_Overview/3_Modules/3_Shared%20modules/shared-module-property-injection.e2e-spec.ts) 与 [shared-module-provider-property-injection.e2e-spec.ts](../../../test/1_Overview/3_Modules/3_Shared%20modules/shared-module-provider-property-injection.e2e-spec.ts) 各有 1 个测试通过，分别验证 Controller 和 Provider 的属性注入也能共享导出的 Provider。
- [module-re-export.e2e-spec.ts](../../../test/1_Overview/3_Modules/4_Module%20re-exporting/module-re-export.e2e-spec.ts) 的 1 个测试已通过，验证根模块可经由 `CoreModule` 再导出的 `CommonModule` 注入 `CommonService`。

## 当前范围

当前已实现模块递归发现、Controller 构造函数/属性注入和 Provider 属性注入，以及通过模块 `exports` 再导出已导入模块；上述行为均有对应测试通过。导出声明的提前校验尚未实现；多层再导出虽由递归查找支持，但目前只验证了一层转发。这些限制不等同于 NestJS 的完整模块行为。
