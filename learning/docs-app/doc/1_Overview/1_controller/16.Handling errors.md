## 官方内容依据

以下内容依据你粘贴的官方原文：异常处理（工作中遇到 exceptions）由 [Exception filters](https://docs.nestjs.com/exception-filters) 章节讲解。

## 当前检查与范围

- 该标题没有独立控制器行为或示例，不在这里重复创建异常处理用例。
- 当前学习版未发现控制器异常过滤器的 `@Catch()`、`@UseFilters()` 或全局过滤器流程；路由冲突异常属于应用初始化阶段，不等同于请求阶段的异常过滤。
- 控制器请求异常及过滤器调用链留待学习官方 Exception filters 章节时再跟进。
