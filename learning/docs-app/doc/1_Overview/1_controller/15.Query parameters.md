# Query parameters：学习锚点与进度

官方章节：[Controllers - Query parameters](https://docs.nestjs.com/controllers#query-parameters)

## 官方内容依据

以下内容依据你粘贴的官方原文：使用 `@Query()` 提取查询参数；如 `age` 和 `breed` 这样的值在请求中以字符串到达，TypeScript 的 `number` 类型注解不会自动转换，需用 pipe 转换。嵌套对象或数组需要 HTTP adapter 配置适当的 query parser；官方分别展示 Express `extended`、Fastify `querystringParser` 和 Node `querystringParser`，并提示 `qs` 支持嵌套和数组。

## 核心数据流与边界

- `NestApplication.set()` 将配置透传给底层 Express 应用；Express 的 `extended` parser 在路由处理前把 query 字符串解析为对象和数组。
- `@Query()` resolver 不负责解析或转换，只读取 `request.query`；参数值仍是字符串，只有 pipe 转换后才成为数字。
- ⏸️ 用户决定暂缓 Fastify 与 Node adapter 的 `querystringParser` 配置；学习版目前仅支持 Express。
