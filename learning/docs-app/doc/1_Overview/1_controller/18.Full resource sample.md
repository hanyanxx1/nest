# Full resource sample：学习锚点与进度

官方章节：[Controllers - Full resource sample](https://docs.nestjs.com/controllers#full-resource-sample)

## 官方内容依据

以下内容依据你粘贴的官方原文：`CatsController` 将 `@Post/@Get/@Put/@Delete` 与 `@Body/@Query/@Param` 组合，展示创建、查询、读取单条、更新和删除等资源路由。示例返回说明性字符串，不实现实际数据库操作。官方还提示 Nest CLI CRUD generator 可生成样板代码。

## 已有覆盖

- 资源路由及 `GET`、`POST`、`PUT`、`DELETE` 等方法注册已在 [Resources](./4.Resources.md) 对应测试中覆盖。
- `@Query()`、`@Body()`、`@Param()` 分别已有请求数据用例；DTO 运行时类型与 pipe metatype 也已在 [Request payloads](./14.Request%20payloads.md) 中学习。
- [full-resource-sample.e2e-spec.ts](../../test/1_controller/18_full_resource_sample/full-resource-sample.e2e-spec.ts) 已通过：`PUT /cats/42` 同时将路径参数 `'42'` 注入 `@Param('id')`，并将 JSON 请求体注入 `@Body()`。

## 学习版范围与进度

- CRUD generator 属于 CLI 样板生成工具，不新增手写 Nest 核心机制；本标题只需说明其用途。
- Full resource sample 的资源路由组合已完成学习版覆盖；本用例关注同一处理方法的两个参数位置，不重复验证各 HTTP 方法和单个参数装饰器。
