# Controllers：章节概述

官方章节：[Controllers](https://docs.nestjs.com/controllers)

## 本节内容概括

Controllers 负责接收应用的 HTTP 请求并向客户端返回响应。路由机制根据请求匹配控制器及其处理方法；一个控制器可以包含多个路由，每个路由处理不同的请求。

Nest 使用类和装饰器描述控制器及路由。装饰器把必要的元数据关联到类和方法，Nest 在应用启动时读取这些元数据，建立请求到处理方法的路由映射。

## 应用启动流程验证

学习版的 `NestFactory.create()` 只创建应用并保存路由注册逻辑，路由在 `init()` 时才注册，与官方一致。这样 `app.use()` 注册的中间件会排在路由前面。`listen()` 会先调用 `init()`，所以 `main.ts` 里 `create()` 加 `listen()` 的写法不需要手动初始化。

- ✅ `app.use()` 注册的中间件先于控制器路由执行：[session.e2e-spec.ts](../../test/1_controller/3_request-object/session.e2e-spec.ts)
- ✅ 不手动 `init()`，只调用 `listen()` 就能命中路由，并通过 `close()` 关闭服务：[listen.e2e-spec.ts](../../test/1_controller/1_controllers/listen.e2e-spec.ts)
