# Sub-domain routing：学习锚点与进度

官方章节：[Controllers - Sub-domain routing](https://docs.nestjs.com/controllers#sub-domain-routing)

## 官方内容依据

以下内容依据你粘贴的官方原文：`@Controller()` 可通过 `host` 限制控制器匹配的请求主机名；host 模式也可包含动态 token，并通过 `@HostParam()` 读取。官方提示 Fastify 不支持嵌套路由器，因此该能力需使用支持此路由方式的平台适配器。

## 用例与进度

- ✅ `request-context.e2e-spec.ts` 中的动态 host 模式 `:account.example.com` 会匹配对应 host，不匹配的 host 返回 404。
- ✅ 同一文件使用 `@HostParam('account')` 注入单个 host 参数，并使用 `@HostParam()` 注入全部 host 参数。
- 学习版使用 Express adapter；Fastify 适配器及其兼容性不在当前学习版范围内。

## 学习版实现线索

- `@Controller({ host })` 将 host 配置写入 `HOST_METADATA`。
- `RouterExplorer` 将 host 元数据附加到发现的路由；请求执行时检查 host，匹配后把动态值放入 `request.hosts`。
- `@HostParam()` resolver 从 `request.hosts` 中读取指定值，或返回全部 host 参数。
