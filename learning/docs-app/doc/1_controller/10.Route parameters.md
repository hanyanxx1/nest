# Route parameters：学习锚点与进度

官方章节：[Controllers - Route parameters](https://docs.nestjs.com/controllers#route-parameters)

## 官方内容依据

以下内容依据你粘贴的官方原文：路径中的 `:id` 一类参数令静态路由可以接收动态值；`@Param('id')` 可直接注入指定参数，`@Param()` 则注入整个路由参数对象。参数路由应放在静态路由之后，避免截获静态路由请求；冲突检测和 specificity 排序已在 Route conflicts 标题学习。

## 用例与进度

- ✅ 同一文件中 `GET /cats/:id/details` 使用 `@Param()` 注入全部路径参数。

## `@Param('id')` 数据流

1. 类定义阶段，`Param('id')` 创建参数装饰器；它把 `{ decorator: 'Param', options: { name: 'id' } }` 按参数索引写入 `PARAM_DECORATORS_METADATA`，关联到控制器原型和 `findOne` 方法。
2. `ExpressAdapter` 将 `cats/:id` 路径交给 Express 注册；请求匹配后，Express 将捕获的值放入 `request.params`。
3. 请求处理时，`RouterExplorer` 按控制器原型和方法名读取参数元数据，并按 `decorator` 选择 `Param` resolver。
4. `Param` resolver 将 `request.params` 与可选的参数名交给 `getNamedValue`：指定 `id` 时返回 `request.params.id`；不指定名称时返回整个 `request.params` 对象。结果按参数索引放进处理方法的参数数组。

Nest 官方也在 `RouteParamsFactory` 中按 `RouteParamtypes.PARAM` 从 `req.params` 取单个值或整个对象；学习版以 resolver 映射和 `getNamedValue` helper 实现相同的基础行为。
