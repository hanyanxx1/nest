# Provider registration：学习锚点与进度

官方章节：[Providers - Provider registration](https://docs.nestjs.com/providers#provider-registration)

## 官方内容讲解

Controller 和 Provider 定义好后，需要把它们登记到模块元数据中：Controller 放进 `controllers` 数组，Provider 放进 `providers` 数组。Nest 据此找到 Provider，并解析 Controller 对它的依赖。

## 学习版实现

- `@Module()` 把模块类的 `controllers`、`providers` 列表写入元数据。
- [NestFactory](../../@nest/core/nest-factory.ts) 读取根模块的 `providers`，按 Provider 类创建实例并存入 Map；创建 Controller 时，根据构造函数的类类型从 Map 中查找并注入实例。
- 当前仅覆盖根模块直接登记的 Provider；模块 `imports`、`exports` 和跨模块可见性不在本节范围内。

## 已有用例与验证

- 复用 [provider-injection.e2e-spec.ts](../../test/2_Providers/1_providers/provider-injection.e2e-spec.ts)：模块通过 `providers: [CatsService]` 登记服务，并在 `controllers` 中登记依赖它的 Controller；HTTP 请求返回 `['Milo']`。
