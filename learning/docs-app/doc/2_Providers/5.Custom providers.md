# Custom providers：学习锚点与进度

官方章节：[Providers - Custom providers](https://docs.nestjs.com/providers#custom-providers)

## 官方内容讲解

Nest 的 IoC 容器不只管理基于类的 Provider，也可以管理普通值、类，以及同步或异步工厂形式的 Provider。本小节没有展开这些形式的代码，而是指向独立的 [Custom providers](https://docs.nestjs.com/fundamentals/custom-providers) 文档。

## 学习版现状

- [ModuleMetadata](../../@nest/common/interfaces/modules/module-metadata.interface.ts) 当前将 `providers` 限定为 `Function[]`。
- [NestFactory](../../@nest/core/nest-factory.ts) 将每个 Provider 当作类，用 `Reflect.construct()` 创建实例，并以类本身作为 Map key。
- 学习版没有 `@Inject()`、字符串或 symbol token、value provider、factory provider，也没有异步 Provider 解析。
- 当前 Providers 用例均使用类 Provider。

## 范围与进度

本小节目前完成概念范围梳理；Custom provider 的具体注册、token 查找和工厂解析尚未实现或验证。由于官方此处将代码示例指向独立章节，开始测试前应先读取该详细章节，避免凭空猜测各 Provider 形式的行为。
